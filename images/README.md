# images/

Drop your real property photos here.

Recommended:
- **Hero image** (`hero.jpg`) — 2400×1600 or larger, landscape
- **Gallery images** (`01.jpg`, `02.jpg`, ...) — 1400px on the long edge
- Compress before uploading (try [squoosh.app](https://squoosh.app) — target ~200KB per image)

Then update the `src=""` attributes in `index.html`, `gallery.html`, and `book.html` to point to `images/hero.jpg`, `images/01.jpg`, etc.
